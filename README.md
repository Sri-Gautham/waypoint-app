# Waypoint

A travel companion app for planning group trips: create a trip group, invite members, share a destination, coordinate carpools, chat, and split expenses.

## Structure

- `design/` — Design canvases (clickable prototypes) built with Claude Design, covering onboarding, the home dashboard, trip detail, chat, and group creation.
- `app/` — Flutter app (iOS + Android).

## Status

Early design/prototyping phase. See `design/onboarding-directions/` for the current interactive prototype.
